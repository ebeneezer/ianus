Objektfluss

  1. Host-Objekt aus dem Archiv in den leeren Workspace ziehen. Er öffnet sich mit drei inneren Objekten: Repo, Archives, Config.
  2. Jedes im Workspace geöffnete Objekt erscheint rechts als eigenes Detailpanel – automatisch nebeneinander oder untereinander angeordnet.
  3. Archives öffnen, Snapshot wählen: Dateibaum des Snapshot-Zeitpunkts. Navigation per Klick, Funktionen per Rechtsklick.
  4. Repo zeigt den gemergten, versionierten Baum (v-Badge = Anzahl Versionen). Blatt-Rechtsklick öffnet die Historie – jede Version einzeln vormerkbar.
  5. Dateien per Drag auf das Restore-Dock ziehen oder per Rechtsklick vormerken. Die gepinnte Version steht auf jedem Chip.
  6. Host im Workspace schließen: Workspace und alle Details leeren sich. Der Restore-Job überlebt (gepinnte Versionen).

Ist richtig, dass der Restore-Job das Schließen des Hosts überlebt? Und: Sollen die Hosts auch im zusammengeklappten Archiv-Streifen sichtbar bleiben oder genügen Icons?
