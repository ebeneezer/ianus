Objektfluss

  1. Host aus dem Archiv-Panel in den Workspace ziehen.
  2. Repo-Konfiguration oder Datenbestand aus dem Workspace nach rechts ziehen.
  3. Im Datenbestand Repo oder Archiv ziehen: Repo zeigt den gemergten versionierten Baum, Archiv den Snapshot-Baum. Ein Klick auf ein Blatt zeigt dessen Versionen.
