Objektfluss

  1. Host in den Workspace ziehen: er öffnet sich mit Repo · Archives · Config. Jedes dort geöffnete Objekt erscheint rechts als Detail.
  2. Snapshot-Objekte tragen eine Knopfleiste im Rahmen: Filter, Markieren, Restore, Historie, Aufklappen. Der Rechtsklick bleibt als Abkürzung.
  3. Blätter per Rechtsklick vormerken oder auf ein Task-Objekt unten ziehen: es entsteht/ändert sich ein Restore-Task im Entwurf – das Panel bleibt offen.
  4. Repo-Objekt → Filter-Objekt (Rechtsklick): Dialog-Objekt in der Details-Pane, Nachbarn minimiert. „Als Task committen“ erzeugt ein neues Task-Objekt.
  5. Host schließen (✕) bei offenen Details: Bestätigungs-Dialog ersetzt das Objekt – bestätigen räumt auf, abbrechen zeigt es wieder.
  6. Beim Schließen eines Objekts blitzt das Eltern-Objekt kurz auf – kein Breadcrumb-Band.
  7. Panes per Maus verändern (Griff zwischen den Spalten, Doppelklick setzt zurück). Layout und geöffneter Zustand werden sofort gesichert und überstehen Neuladen und Backend-Restart – im Produkt persistiert der Daemon sie im cfg/-Keyspace.
